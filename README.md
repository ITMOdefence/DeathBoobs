# DeathBoobs

DeathBoobs — специализированная встраиваемая база данных для страйкбольного приложения.

Приложение обрабатывает изображение с камеры, обнаруживает цель, вычисляет её координаты, азимут и расстояние. DeathBoobs сохраняет результаты этих вычислений, историю игровых сессий и связанные данные.

База работает локально внутри приложения по модели embedded database и не является универсальной СУБД. Обработка изображения и вычисление параметров цели находятся за пределами базы данных.

## Статус

Проект находится на этапе проектирования.

## Первая версия

Первая рабочая версия должна поддерживать:

- хранение данных в собственном файле базы;
- постраничное чтение и запись;
- сохранение игровых сессий и обнаружений целей;
- чтение истории обнаружений;
- поиск записей по идентификатору;
- выборку обнаружений по игровой сессии и времени;
- атомарную запись и восстановление после сбоя;
- сохранение данных между запусками приложения.

## План развития

1. Утвердить модель данных и формат файла.
2. Выбрать язык реализации и инструменты сборки.
3. Реализовать менеджер файлов и страниц.
4. Реализовать хранение игровых сессий и обнаружений.
5. Добавить индексы для основных сценариев чтения.
6. Добавить транзакции, журналирование и восстановление.
7. Интегрировать базу со страйкбольным приложением.

## Реализация

Проект реализуется на C11 поверх системных библиотек PUNos. Текущий этап — файловое хранилище.

```sh
make all PUNOS_DIR=/path/to/PUNos
make check PUNOS_DIR=/path/to/PUNos
```
