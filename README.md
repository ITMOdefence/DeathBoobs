# DeathBoobs

DeathBoobs — специализированная встраиваемая база данных для страйкбольного приложения.

Приложение обрабатывает изображение с камеры, обнаруживает цель, вычисляет её координаты, азимут и расстояние. DeathBoobs сохраняет результаты этих вычислений, историю игровых сессий и связанные данные.

База работает локально внутри приложения по модели embedded database и не является универсальной СУБД. Обработка изображения и вычисление параметров цели находятся за пределами базы данных.

## Статус

Реализована часть 2: модели записей, little-endian кодек, публичный Database API
и индексы в оперативной памяти. Unit tests используют fake Storage/Transaction.
В этом checkout настоящие Storage и Transaction пока представлены публичными
интерфейсами; работа с физическим файлом и crash recovery ещё не реализованы.

## Первая версия

Первая рабочая версия должна поддерживать:

- хранение данных в собственном файле базы;
- постраничное чтение и запись;
- сохранение игровых сессий и обнаружений целей;
- чтение истории обнаружений;
- поиск записей по идентификатору;
- выборку обнаружений по игровой сессии и времени;
- атомарную запись и восстановление после сбоя;
- сохранение данных между запусками приложения.

## Реализация

Проект реализуется на C11 поверх системных библиотек PUNos. Database использует
только публичные Storage/Transaction API и `libmem`, без прямого доступа к файлу.

## Проверка части 2

Для 64-битного хоста с C11-компилятором и checkout PUNos в соседнем `../PUNos`:

```sh
sh tests/run.sh
```

Другой путь к PUNos задаётся через `PUNOS_ROOT`. Сборка использует настоящие
PUNos-заголовки и `-Wall -Wextra -Werror`. Перед unit tests проверяются production
объекты freestanding при `-O0` и `-O2`: допустимы только публичные зависимости,
скрытые ссылки на libc `memcpy`/`memset` отклоняются. Нужны также `nm` и POSIX
shell/awk. Тестовые объекты и бинарники создаются во временном каталоге вне
репозитория и автоматически удаляются. Инструмент проверки символов можно
выбрать через `NM`.

С AddressSanitizer и UndefinedBehaviorSanitizer:

```sh
CC=clang DEATHBOOBS_SANITIZE=1 sh tests/run.sh
```
